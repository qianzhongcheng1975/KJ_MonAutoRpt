# KJ_MonAutoRpt 开发计划与里程碑（MVP -> 可上线）

## 1. 迭代规划

## Sprint 1（基础设施）
**目标**：完成项目骨架与身份体系。
- React + TypeScript 前端初始化。
- Firebase 项目初始化（Auth / Firestore / Storage / Functions）。
- 登录与基础路由。
- users profile 自动建档。
- 初版 Firestore / Storage 安全规则。

**交付物**
- 可登录的前端站点。
- users 集合可读写（按角色约束）。

## Sprint 2（上传与标签）
**目标**：完成素材入库闭环。
- 上传页：文件上传 + 必填标签校验。
- Storage 路径按规范落盘。
- uploads 文档创建与状态反馈。
- `onUploadCreated` 函数框架 + jobs 记录。

**交付物**
- 用户可上传并看到标签化素材记录。
- 标签缺失会被拦截并记录失败信息。

## Sprint 3（概要自动生成）
**目标**：完成自动分析 MVP。
- 二级字段映射表落地（14 个字段）。
- summaries 自动生成/更新（100 字限制）。
- 空素材兜底“本月为空”。
- 概要管理页（列表、编辑、删除、AI 重生成入口）。

**交付物**
- 上传后可按月份看到可编辑 summaries。

## Sprint 4（报告生成与编辑）
**目标**：完成报告构建与编辑。
- `generateMonthlyReport` 实现。
- reports 文档写入与状态流转。
- 报告预览编辑页面。
- PDF 生成并上传 Storage。

**交付物**
- 由 summaries 自动生成报告并可人工修订。

## Sprint 5（邮件与重试）
**目标**：完成投递自动化。
- 接入 SendGrid/Resend。
- `sendReportEmail` 与重试策略（3次、10分钟）。
- settings 页支持收件人/自动发送配置。
- 失败日志与错误信息回写。

**交付物**
- 报告自动投递，失败可自动重试并可追踪。

## Sprint 6（调度、审计、上线）
**目标**：支持无人值守与上线验收。
- Cloud Scheduler（日巡检 + 月末 18:00 强制）。
- 审计日志（upload/analyze/generate/send）。
- 权限规则加固（系统字段仅 Functions 可写）。
- 回归测试 + 上线手册。

**交付物**
- 可持续运行的自动月报系统。

---

## 2. 优先级清单

### P0（必须）
- Auth + users profile
- 上传与标签校验
- summaries 自动生成（含空月兜底）
- report 生成与编辑
- 自动邮件与重试
- 最小权限安全规则

### P1（应有）
- AI 单条概要重生成
- 审计日志看板
- 失败任务告警（邮件/Webhook）

### P2（可选）
- 模板多版本管理
- 批量导出部门月报
- 组织级汇总分析

## 3. 风险与应对
- **OCR/ASR 质量波动**：增加人工修订入口 + source evidence。
- **重复触发/并发覆盖**：函数写入引入幂等键（uid+month+fieldKey）。
- **邮件服务限流**：发送排队与指数退避。
- **权限误配**：上线前执行规则回归测试清单。

## 4. Definition of Done（每迭代）
- 功能说明、接口文档、错误码说明齐全。
- 至少覆盖 happy path + 2 个异常路径。
- 关键日志可定位到 uid、month、jobId。
- 前端对系统字段只读，后端函数负责状态推进。
