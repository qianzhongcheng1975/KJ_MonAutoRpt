# KJ_MonAutoRpt 功能需求梳理（v1）

## 1. 产品目标
构建“上传素材 -> 自动分析 -> 自动生成月报 -> 自动邮件投递”的无人值守月报系统。

### 1.1 关键目标
- 用户侧只需上传带标签素材。
- 系统按月度匹配规则自动生成二级字段概要（每条不超过 100 字）。
- 系统自动生成可编辑月报，支持人工增删改。
- 系统自动发送邮件，失败自动重试并留痕。

## 2. 角色与权限
- **member**：仅能访问并维护自己的 uploads / summaries / reports。
- **admin**：可管理 users、settings，可查看系统运行状态。
- 前端禁止直接修改关键系统字段：`status`、`sentAt`、`retryCount`、`errorMessage`。

## 3. 数据模型（业务约束）

### 3.1 users/{uid}
- `displayName`、`department`、`position`、`email`、`role`
- `createdAt`、`updatedAt`

### 3.2 uploads/{uploadId}
- `uid`、`reportMonth`、`fileUrl`、`fileType`
- `tags.materialCategory`、`tags.contentType`、`tags.moduleKey`
- `parsedText`、`createdAt`

### 3.3 summaries/{summaryId}
- `uid`、`month`、`moduleKey`、`fieldKey`、`fieldLabel`
- `content`（<=100字）、`sourceUploadIds`
- `editable=true`、`createdBy`、`updatedAt`

### 3.4 reports/{reportId}
- `uid`、`month`、`status`
- `name`、`department`、`position`
- `sections`、`summaryMap`、`generatedBy`
- `sentAt`、`createdAt`、`updatedAt`

### 3.5 settings/global
- `materialCategories`、`contentTypes`
- `reportRecipients`
- `autoSend`、`monthEndRunHour`、`timezone`

### 3.6 jobs/{jobId}
- `jobType`、`month`、`uid`
- `status`、`retryCount`、`errorMessage`
- `createdAt`、`updatedAt`

## 4. 存储路径规范
- 上传素材：`/uploads/{uid}/{YYYY-MM}/{uploadId}/{filename}`
- 报告 PDF：`/reports/{uid}/{YYYY-MM}/{reportId}.pdf`

## 5. 业务流程需求

### 5.1 上传触发（实时）
1. 用户上传文件并写入 uploads 文档（标签必填）。
2. `onUploadCreated` 校验标签完整性，不完整则写 jobs 失败原因。
3. 按文件类型提取文本/OCR/ASR。
4. 仅纳入 `reportMonth` 与目标 month 匹配的素材。
5. 写入/更新 summaries：
   - 二级字段 1:1 生成概要。
   - 每条概要最大 100 字。
   - 无可用素材时先给建议，仍无结果写入“本月为空”。

### 5.2 报告生成（自动）
1. `onSummaryChanged` 或 `onMonthEndSchedule` 触发。
2. 读取 users profile（姓名/部门/岗位）。
3. 汇总指定 month 的 summaries 生成月报。
4. 写入 reports，`status=generated`。
5. 支持后续人工改写（增删改）。

### 5.3 邮件发送（自动）
1. `onReportGenerated` 触发。
2. 收件人来自 `settings/global.reportRecipients`。
3. 主题：`{{month}}月工作报告-{{name}}`。
4. 正文简述 + PDF 附件发送。
5. 失败重试 3 次（间隔 10 分钟）。
6. 成功标记 `sent`，失败标记 `failed`。

### 5.4 定时任务
- 每日巡检当月未发送报告并补发。
- 每月最后一天 18:00（系统时区）强制执行一次 `generate + send`。

## 6. 前端页面最小集
- 登录页（Firebase Auth）
- 上传页（文件 + 必填标签）
- 概要管理页（列表、增删改、AI 重生成、100字校验）
- 报告页（预览、编辑、发送状态）
- 设置页（分类、用户、内容、收件人配置）

## 7. 验收标准（MVP）
- 用户上传单份素材后 30 秒内可看到 summaries 更新（非 OCR/ASR 复杂文件）。
- summaries 严格按二级字段映射生成，单条不超过 100 字。
- 报告生成后可人工编辑并保存。
- 自动发送可正常投递；模拟失败后可按策略重试。
- member 无法访问他人数据，且前端无法直接修改关键系统字段。
